# বাজার দর (BazarDor)

BazarDor is a web application that helps users explore daily essential product prices in Bangladesh. Users can browse products, compare market prices, and track daily price changes.

## Technologies Used

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- React Hot Toast

## Key Features

- Daily product prices and price change indicators
- Responsive product cards and category-based browsing
- Product details with market-wise price information
- Email/password authentication with Google and GitHub login
- User profile and information update
- Sort products by price
- Responsive design for mobile, tablet, and desktop

## Getting Started

```bash
git clone https://github.com/shorifulislamdx1-pixel/bazar-dor-as-7.git
cd bazar-dor-as-7
npm install
npm run dev
```

Configure the required environment variables in `.env.local` before running the application.
